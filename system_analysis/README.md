# System Analysis

## Overview

This folder contains the system analysis developed within the DiverSea project for the analysis and visualization of marine biodiversity, ecosystem pressures, and ecosystem services.

The current implementation is provided through the **MARBIOSE Dashboard**, which combines system-dynamics modelling with spatial data and scenario analysis.

## MARBIOSE

The `MARBIOSE` folder contains the implementation and documentation of the MARBIOSE Dashboard.

The dashboard integrates:

* system-dynamics modelling;
* marine biodiversity and ecosystem data;
* spatial datasets;
* spatial scenario analysis;
* seagrass spatial modelling;
* tourism pressure mapping;
* visualization of scenario results.

The spatial scenarios use the system-dynamics model together with spatial information on seagrass distribution, marine traffic, tourism hotspots, and protected areas to investigate how different scenarios can affect the spatial distribution of ecosystem conditions.
